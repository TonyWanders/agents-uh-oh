# The Agent's Uh-Oh

Entry for the make.fun bounty [The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4) by Danu Bee.

## The word

**recalculating**

An agent with no idea what to do says the same thing every lost
satnav says: it is recalculating. Lost, but still working, and too
proud to ask for directions.

## Run it

```
python3 main.py
```

It prints exactly one word, `recalculating`, and nothing else.
The output is deterministic: every run prints the same word.

## Files

- `main.py` - the entrypoint, prints the word
- `entry.txt` - the word on its own
